<h1 align="center">CellMaskViewer</h1>

<p align="center">基于 Go 语言与 MyGo 原生界面构建的生物显微与细胞分割 TIFF 掩码可视化工具。</p>

---

## 解决的问题

在细胞分割、汇合度计算、类器官培育等算法分析输出中，分割掩码通常采用 TIFF 容器存储。常见的图像软件面对此类文件时存在明显问题：

- 常规图片查看器将 16 位整型数据（uint16）按常规灰度显示，由于细胞实例编号（如 1 到 1500）远低于 16 位上限（65535），画面呈现全黑状态，无法分辨实例。
- 传统工具不识别多页 TIFF 中的局部裁剪掩码以及 TIFF Tag 270（ImageDescription）存储的 JSON 元数据包围盒偏移量（`[tx, ty, bx, by]`），导致多页文件无法重组还原为完整视野。
- 难以直接将掩码与同级目录的明场（BF）或荧光（FL）原始图像叠加对比。

CellMaskViewer 专为生物显微与深度学习分割设计，无需安装任何额外运行环境，双击即可运行，直接拖入掩码文件即可完成高对比度伪彩着色与轮廓查看。

## 核心特性

### 1. 直接拖拽即看
无需复杂菜单操作，直接将 `_multimasks.tif` 掩码文件拖入窗口，程序即刻解析并呈现上色结果。同时支持直接拖入 `_source_*.jpg` 底图，或者在拖入掩码文件时自动检索同级或上级目录匹配的原始视野图像进行半透明融合。

### 2. 黄金分割 HSV 伪彩着色
- 实例背景 ID = 0 渲染为完全透明。
- 各细胞实例编号采用黄金分割比例离散算法计算色相：
  $$H = \text{fmod}(k \times 0.618033988749895, 1.0)$$
  相邻编号的细胞在色相环上跨度极大，彻底避免相邻细胞颜色粘连难以分辨。

### 3. 三种主流显示模式
- **只显示轮廓（ModeOutline）**：通过 4-邻域边缘提取算法，仅保留细胞 1 到 2 个像素的外轮廓线，内部完全透明镂空。符合数字病理与显微分析的主流查看习惯，完全不遮挡细胞内部细节。
- **半透明填充（ModeFill）**：各个细胞实例以独立伪彩半透明覆盖。
- **填充加轮廓（ModeBoth）**：内部以低不透明度填充，外边缘以完全不透明的实线进行高亮强化。

### 4. 格式全兼容
- **单页全图矩阵（Single-Page Label Matrix）**：兼容细胞数量超过 255 时的 uint16 / uint32 单页大图格式，内置流式 zlib 解码器，高效解压 Strip 分条数据。
- **多页局部裁剪掩码（Multi-Page Cropped Masks）**：兼容细胞数量不超过 255 时的多页 uint8 格式，自动读取 Tag 270 元数据中的包围盒坐标，准确还原至全图画布。

### 5. 自动更新与国内网络加速
参考 SnapBridge 的更新架构，内置了针对 GitHub 的多通道镜像回退机制（包含 `ghfast.top`、`gh-proxy.com`、`ghproxy.net`、`ghproxy.cfd` 与直连）。用户在工具栏点击「检查更新」，工具即可通过可用通道快速检测最新发布版本，并实现一键自动更新。

## 界面操作与控制

| 控件 / 按钮 | 作用说明 |
| --- | --- |
| **打开文件** | 弹出文件选择对话框，可选择 `.tif`、`.tiff` 掩码或 `.jpg`、`.png` 原图 |
| **文件直接拖拽** | 将文件从资源管理器直接拖入窗口任意区域即可加载 |
| **只显示轮廓** | 切换为边缘轮廓模式，内部镂空 |
| **半透明填充** | 切换为半透明颜色填充模式 |
| **填充加轮廓** | 切换为半透明内部填充加边缘实线高亮模式 |
| **透明度滑动条** | 连续调节掩码颜色图层的透明度（0.1 ~ 1.0） |
| **100% / 50% / 25%** | 缩放显示比例，方便快速适应大视野图像 |
| **检查更新** | 触发自动更新检测流程 |

## 源码结构

- [main.go](main.go)：程序入口与 MyGo 原生桌面窗口布局、控件响应与拖拽事件监听。
- [tiff_reader.go](tiff_reader.go)：基于 `github.com/google/tiff` 与标准库 `compress/zlib` 的多格式 TIFF 解码器。
- [color_lut.go](color_lut.go)：黄金分割 HSV 调色板、4-邻域边缘提取与 RGBA 混合渲染器。
- [update.go](update.go)：多镜像源的 GitHub Release 自动更新客户端。
- [icon.ico](icon.ico) / [icon.png](icon.png)：专属显微细胞应用图标。

## 编译与构建

本工具为纯 Go 语言编写，不依赖 CGO 环境，可在任意配备 Go 1.27+ 的机器上完成编译。

运行目录下的 [build.bat](build.bat) 即可生成嵌入图标的 Windows 独立可执行文件：

```cmd
build.bat
```

也可以直接执行标准构建指令：

```cmd
go build -ldflags "-s -w -H windowsgui" -o "CellMaskViewer.exe" .
```
